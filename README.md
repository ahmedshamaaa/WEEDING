# دعوة زفاف متحركة

نسخة static بسيطة تعمل مباشرة بدون build أو dependencies.

## تشغيل محلي

من داخل المجلد:

```powershell
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

لاختبارها من الموبايل على نفس شبكة الـ Wi‑Fi، استخدم عنوان الكمبيوتر المحلي بدل `localhost`، مثل:
`http://192.168.1.10:4173`
